# Hello World

[English](README.md) | [简体中文](README_ZH.md)

## 功能

初始化 MIPI-DSI 显示屏并显示基础 Arduino_GFX 画面。

## 硬件需求

- ESP32-P4-WIFI6-Touch-LCD-4B 开发板

## 怎么运行

1. 安装 Arduino-ESP32 3.3.11，选择 ESP32P4 Dev Module。
2. 设置 PSRAM 为 Enabled、Flash Size 为 32 MB、Chip Variant 为 v3.00 or newer。
3. 打开 `01_HelloWorld.ino` 并上传。

## 预期现象

显示屏完成初始化并显示示例内容。
