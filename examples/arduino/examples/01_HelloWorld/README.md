# Hello World

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Initializes the MIPI-DSI display and shows a basic Arduino_GFX screen.

## Hardware Required

- ESP32-P4-WIFI6-Touch-LCD-4B development board

## How to Run

1. Install Arduino-ESP32 3.3.11 and select ESP32P4 Dev Module.
2. Set PSRAM to Enabled, Flash Size to 32 MB, and Chip Variant to v3.00 or newer.
3. Open `01_HelloWorld.ino` and upload it.

## Expected Result

The display initializes and renders the example output.
