# Audio Playback

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Plays a short tone sequence through the ES8311 codec and on-board speaker.

## Hardware Required

- ESP32-P4-WIFI6-Touch-LCD-4B development board

## How to Run

1. Install Arduino-ESP32 3.3.11 and select ESP32P4 Dev Module.
2. Enable PSRAM, select 32 MB flash, and select Chip Variant v3.00 or newer.
3. Upload `09_Audio_Playback.ino`.

## Expected Result

The on-board speaker plays the tone sequence.

## Troubleshooting

Keep the speaker path unobstructed while listening.
