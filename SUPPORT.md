# Support

[English](SUPPORT.md) · [简体中文](SUPPORT_ZH.md)

Use the repository issue tracker for reproducible problems with examples,
documentation, or repository automation. Include the example path, exact
framework version, board revision, reproduction steps, expected behavior, and
actual behavior.

For purchasing, warranty, replacement, and general product questions, use the
support options linked from the official
[Waveshare product page](https://www.waveshare.com/esp32-p4-wifi6-touch-lcd-4b.htm).

Do not place credentials, private keys, private network names, personal data,
or undisclosed vulnerability details in a public issue. This repository does
not currently advertise a verified private vulnerability-reporting endpoint.
Maintainers must enable and verify such a channel before publishing a security
reporting policy.
