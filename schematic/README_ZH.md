## 硬件边界

主板原理图涵盖 ESP32-P4、显示屏、触摸、音频、摄像头、MicroSD、USB 和 ESP32-C6 连接。
底板原理图涵盖 IP101 以太网 PHY、继电器和 RS485 收发器。

使用以太网、继电器或 RS485 的示例需要完整匹配的 86 面板硬件总成。独立 4B 开发板不含这些
电路，官方产品页面标示的是不同的主 PCB 和外壳配置，而不是可直接加装的底板升级。

## 版本特定的发现

历史 V1.3 底板图纸将 RS485 `/RE` 和 `DE` 相连，并将该网络上拉，这可能使收发器保持在发送模式
并禁用其接收器。该结论适用于审阅过的 V1.3 图纸。在将其应用到其他版本前，请确认实际开发板
和当前官方底板原理图。

不要为了回环测试而短接 RS485 A 和 B；在了解方向控制和总线所有权之前，也不要连接另一个
正在主动驱动的适配器。

## 审阅规则

- 记录引脚或电路时，请引用精确文件和可见版本。
- 将原理图事实与 `../docs/board_ZH.md`、BSP 常量及使用该外设的示例交叉核对。
- 将编译仅视为 API 验证；它不能验证电路。
- 记录未解决的差异，不要臆测地从最新文件中选择一个值。
- 在实际可行时保留原始供应商文件名，以便仍可轻松验证源哈希。

本次文档/导入工作未进行电气测量或板上验证。
