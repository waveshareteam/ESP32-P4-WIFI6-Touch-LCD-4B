# P4 与 C6 Hosted Wi-Fi 兼容性

[English](p4-c6-hosted-wifi.md) · [简体中文](p4-c6-hosted-wifi_ZH.md)

ESP32-P4 没有集成 Wi-Fi 射频。本开发板通过 SDIO 使用 ESP32-C6-MINI-1U-H8 协处理器。P4 主机软件
和 C6 从机固件构成一个兼容性约定；仅更新 P4 一侧可能导致构建成功但无线硬件无法工作。

## 主机端基线

当前 ESP-IDF 主机依赖基线为：

- `espressif/esp_wifi_remote` 1.6.3。
- `espressif/esp_hosted` 2.12.11。
- 使用 SDIO 传输和 ESP32-C6 作为从机目标。

`esp_wifi_remote` 1.6.3 声明依赖 `esp_hosted >=2.11,<3.0`。在未有意迁移完整主机和从机协议栈前，
不要将其与 ESP-Hosted 3.x 配对。

## 缺失的 C6 材料

2026-07-30 审阅的官方 ESP32-P4-WIFI6-Touch-LCD-4B 示例归档不包含：

- C6 从机固件二进制文件。
- C6 从机源代码。
- C6 构建或烧录说明。
- 工厂安装镜像的版本标识符。

本仓库尚未包含这些材料，后续更新可能会添加。不得将其缺失描述为它们已关闭、永久不可用或不兼容的证据。

## 安全更新流程

1. 记录当前主板版本，以及能否从设备日志或协议读取 C6 固件标识符。
2. 固定 P4 主机依赖版本；不要使用不受约束的 `"*"` 范围。
3. 为每个维护的 IDF 版本构建 P4 主机。
4. 在不替换 C6 镜像的情况下烧录 P4 应用，并验证 SDIO 枚举、站点扫描、关联、DHCP、持续流量和重连行为。
5. 如果变更 C6 镜像，请保留恢复副本，并与每个维护的 P4 主机表面一同测试。
6. 将精确的可工作主机/从机组合记录在此矩阵中。

## 故障解释

- 依赖解析或编译失败是 P4 主机构建问题。
- SDIO 初始化、RPC 或版本协商失败可能是主机/从机协议不匹配。
- 关联成功但流量不稳定，仍可能表明缓冲、流控、供电或固件兼容性问题。
- 编译成功绝不会验证已安装的 C6 镜像。
