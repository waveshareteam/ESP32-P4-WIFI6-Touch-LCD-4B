[English](licensing.md) · [简体中文](licensing_ZH.md)

尚未选择仓库范围的许可证。不要从子组件、SPDX 头、依赖清单或上游仓库推断许可证。
本文档记录观察到的边界；它不是法律意见，也不授予使用或再分发任何材料的许可。

## 来源不是许可

`docs/sources_ZH.md` 记录官方 URL 和 SHA-256 哈希。这些记录说明导入材料来自何处以及审阅了哪个归档。
它们不能证明每个文件都可以再发布、修改、销售或包含在二进制产品中。

2026-07-30 审阅的官方产品示例归档不包含归档范围的顶层许可证。对于没有单独条款的导入材料，
在公开再分发前，应从权利持有人处获得明确的仓库许可证或其他授权。

## 仓库范围许可证

不要通过复制下列任一位置的许可证来添加 `LICENSE.txt`：

- `firmware/brookesia/components/brookesia_core/license.txt`。
- Waveshare BSP 或驱动包。
- GFX Library for Arduino 或 LVGL。
- Xiaozhi 第三方代码。
- ESP-IDF 示例源文件头。

这些条款仅适用于各自的材料。仓库所有者必须选择并记录与所有包含的源代码和资源兼容的仓库范围许可证。

## 导入的 Waveshare 材料

规范化的 ESP-IDF 示例、Arduino 草图、产品专用 Arduino 辅助库、原理图和 2D 图纸均源自官方产品资源。
请保留来源记录和厂商声明。在确认再分发权利前，链接到官方下载并不等同于获准镜像其内容。

硬件 PDF 和 DXF 文件是参考文档，并不自动成为开源硬件设计文件。除非适用的厂商条款允许，否则不要声称
有权制造、修改或再分发它们。

## 托管组件

托管依赖即使在构建期间下载或链接到固件镜像中，仍是独立作品。在任何需要它们的分发中，保留其包许可证和声明。

发布的 Waveshare 4B BSP 3.0.1 包含 Apache-2.0 许可证文本。这并不为整个仓库授予许可证。

ST7703 2.0.0 材料需要上游澄清：其组件清单标识为 MIT，提供的 MIT 文本含有未填充的版权占位符，
而源文件头标识为 Apache-2.0。不要通过在本地编辑许可证或断言某一种解释来解决该冲突。请跟踪上游修正，
同时保留所有声明。

## 第三方源代码和库

- 官方示例归档与仓库 CI 使用完整随附的 GFX Library for Arduino 1.6.0 源码树；其 BSD 风格
  许可证文件保留在随附目录中。

- 本地 Brookesia 核心包含仅适用于该组件的 Apache-2.0 条款。
- Xiaozhi 第三方目录包含仅适用于该目录的 MIT 条款，并明确记录导入 OGG 提示音的来源。
- Espressif 派生的示例文件可能带有各自的 SPDX 标识符；请保持这些文件头完整。

如果通用 Arduino 库由构建环境安装而不是随仓库提供，发布与源代码分发仍需满足实际使用版本的许可证要求。

## 媒体和生成资源

将音频、字体、图标、生成的 C 数组和模型数据与源代码分开处理。尤其应：

- 确认 `canon.pcm` 的来源和再分发条款。
- 对包含 Xiaozhi OGG 提示音的源码或二进制分发，保留已记录的提示音来源与 MIT 许可证。
- 在记录其再分发权利前，不要添加 MP3 曲目。
- 再分发字体二进制文件或生成数组时，保留字体许可证和声明。
- 记录应用图标及其他图稿的来源和许可证。

已提交的定版 Brookesia rev3_x 镜像在 `../THIRD_PARTY_NOTICES_ZH.md` 中有精确发布清单，记录了
`78/xiaozhi-fonts` 1.6.0、`espressif/esp-sr` 2.4.7、`lvgl/lvgl` 9.4.0、Xiaozhi
提示音来源提交以及相关本地组件声明。为 `xiaozhi-fonts` 记录的 Registry 元数据不会创建额外下游许可；
后续重建必须按新解析的软件包与负载重新审阅。

文件可在运行时使用，并不能证明拥有分发它的许可。

## 发布或发版前

1. 记录项目所有者是否选择仓库范围许可证；未选择时不授予一般下游权限。
2. 在分发前解决、移除，或明确保留并上报条款未知或冲突的文件。
3. 保留所有逐文件 SPDX 文件头和捆绑许可证文件。
4. 使用分发中包含的精确版本和材料更新 `../THIRD_PARTY_NOTICES.md`。
5. 审查生成的固件是否存在链接组件的声明义务。
6. 将硬件文档和媒体与源代码分开审查。
7. 确认公开文本或产物中不含本地路径、凭据或用户数据。

已提交镜像的清单为该定版源码构建闭合了组件/媒体清点步骤，但不豁免上游条款，也不授权不同构建。
根目录不存在许可证表示“尚未授予仓库范围的许可”，而不是选择了默认许可证。
